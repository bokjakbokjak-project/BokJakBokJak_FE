# 마이페이지 미결정 사항

마이페이지(Figma Section `732:4459`)에서 확인이 필요한 항목이다. 질문 형식과 상태 값은 [설문 문서](../question/README.md)를 따른다. 답변 근거 없이 결정 상태로 바꾸지 않는다.

## Figma에 적힌 디자이너 메모

- 프레임 아래 메모(`793:5203`): "상황형 질문끝나면 내 프로필 보여주기(이때 공유하기오른쪽 상단에) / 마이페이지 화면 보여주기 / 상세프로필 보러가기> 마이페이지와 동일". 설문 결과 프로필은 이미 공유 버튼이 오른쪽 위에 있어 이번 작업에서 바꾸지 않았다.

## 화면 구성

- 긴 프레임(`1532:19717`, 390×2040)은 스크롤한 전체 내용이다. 화면은 390×844 안에서 하단 메뉴 위만 스크롤된다.
- 카드에는 설문 주제의 본인 질문 문구를 표시하고, `나의 성향`은 본인 질문 답변, `원하는 성향`은 룸메이트 질문 답변이다.
- 새로고침하면 메모리의 답변이 사라진다. 서버 저장은 정해지지 않았다(설문 문서 BE-9).
