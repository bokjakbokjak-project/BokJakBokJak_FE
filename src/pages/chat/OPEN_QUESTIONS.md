## CH-2: 안건 진행과 채팅방 종료 규칙

- 현재: Figma `1715:38109`, `1858:17915`의 새 디자인대로 진행 중인 채팅방의 가장 최근 안건 카드 안에 `다음안건으로`와 `매칭확정 하기`가 있다(QA 6). 하단 `조율 확정 메뉴`는 없앴다.
- 현재: `다음안건으로`는 확인 창(`다음 안건으로 넘어가시겠습니까?`, 프로젝트 담당자 요청으로 Figma의 `이대로 확정하시겠습니까?`에서 바꿈) 뒤에 안건을 확정하고, 같은 자리가 `안건 확정 취소하기`로 바뀐다. 취소는 확인 없이 바로 된다.
- 현재: `매칭확정 하기`는 확인 창(`매칭을 확정하시겠습니까?`, `1858:18674`) 뒤에 내 확정만 저장하고, 같은 자리가 `매칭확정 취소하기`로 바뀐다. 상대도 확정해야 최종 매칭이 되므로 매칭 완료 처리는 서버 몫으로 남겼다.
- 현재: 오른쪽 위 빨간 나가기 아이콘(`1952:40302`)이 메뉴 화면을 대신한다(QA 8). 누르면 `정말로 채팅을 종료하시겠습니까?` 확인 창(`1952:40268`)이 뜨고, `나가기`는 기존 종료 요청(`endRoom`)으로 채팅방을 종료 상태로 바꾼 뒤 목록으로 간다. 이미 종료된 방은 목록으로만 간다. 새 삭제 기능은 만들지 않았다. `대화방에서 나가기`는 뒤로가기와 겹쳐 메뉴 화면과 함께 없앴고, 옛 메뉴 주소(`/chat/:id/menu`)는 채팅방으로 보낸다. 상대 프로필은 대화 속 상대 캐릭터를 눌러 연다.
- 충돌: 확인 창 문구는 `채팅을 종료하면 모든 채팅내역이 사라지게 됩니다`지만, 시연 데이터는 대화 기록을 지우지 않고 종료 상태로만 바꾼다. 실제 삭제 여부는 서버 규칙이다.
- 충돌: 안건 확인 창은 `안건을 확정하면 다시 수정할 수 없어요`라고 안내하지만, 확정 뒤 취소 버튼이 남아 있다.
- 질문: 한 명만 눌러도 넘어가는가, 둘 다 눌러야 하는가? 종료하면 기록이 정말 사라지는가? 매칭 확정은 언제 결정되고, 내 확정을 취소할 수 있는가?
- 답변 전: 현재 임시 동작을 유지하고 서버 규칙으로 설명하지 않는다.

## 시연 데이터의 범위

모든 상대는 룸메이트 예시 데이터의 후보다. 이름과 매칭률이 같고, 상대 캐릭터를 누르면 그 후보의 매칭 분석이 열린다. Figma 목록의 한수희, 진서율은 룸메이트 데이터에 없어 이서윤, 박지민으로 바꿨다.

| 방     | 상태                       | 근거         |
| ------ | -------------------------- | ------------ |
| 민수정 | 매칭 확정                  | `940:19880`  |
| 이서윤 | 내가 다음 안건을 요청함    | `988:16735`  |
| 서유정 | 대화 중                    | `988:19036`  |
| 박지민 | 첫 안건 확정, 둘째 진행 중 | 예시로 작성  |
| 김혜나 | 대화 시작                  | 예시로 작성  |
| 남윤경 | 시작                       | `897:11605`  |
| 전혜윤 | 중간 종료                  | `1236:14142` |
| 최하은 | 시작                       | `897:11605`  |

시간은 `오늘`, `어제`, `2일전`, `3일전`으로 나눴다. 보낸 메시지, 투표, 종료는 메모리에만 반영되고 새로고침하면 처음 상태로 돌아간다.

## DE-C6: 채팅방 새 디자인의 빈 자리

- 현재: 채팅방을 Figma `1715:38109`로 바꿨다. 첫 메시지로 AI 소개 카드(`안건 조율을 시작할께요!`)와 조율 안건 목록을 보여준다.
- 챗봇 이름: Figma는 `챗봇이 이름`, `"00"`으로 비워 두었다. 지금은 `AI 챗봇`으로 표시한다.
- Figma에 없는 상태: 확정된 안건 카드는 `미정` 자리에 갈색 `확정` 배지를 붙였다. 확정한 뒤의 메뉴 문구(`안건 확정 취소하기`, `매칭확정 취소하기`), 보낼 내용이 없을 때 흐린 전송 버튼은 임시 디자인이다.
- 나가기 아이콘: Figma대로 빨간 원이 항상 보인다. 메뉴 버튼은 없어졌다(CH-2).
- 질문: 챗봇 이름은 무엇인가? 확정 카드, 취소 버튼, 비활성 전송 버튼의 디자인은 무엇인가?
- 답변 전: 임시 표시를 유지하고 최종 디자인으로 간주하지 않는다.

## DE-C7: 목록 배경과 말풍선 줄바꿈

- 목록 배경(QA 9): 위쪽 파란 하늘을 홈 화면과 같은 아이보리로 바꿨다. 홈 화면이 방 그림 위에 까는 그라데이션(`brand-cream1`, 위 258px)을 그대로 썼다. 최신 Figma(`1981:16727`)에는 아직 파란 배경이 남아 있다.
- 줄바꿈(QA 7): 말풍선 글자 영역은 258px까지 넓어지고 그 뒤로 줄을 바꾼다. 내 말풍선은 좌우 16px 여백과 테두리를 더해 최대 292px, 상대 말풍선은 좌우 12px로 최대 284px이며, 작은 화면에서는 화면 폭을 넘지 않는다. 한글은 단어 단위로 바꾸고, 공백 없는 URL과 영문·숫자는 글자 단위로 끊는다. 입력한 줄바꿈과 공백은 그대로 보인다. 지금 입력창은 한 줄 입력이라 줄바꿈은 입력할 수 없다.

## 서버 연동 (채희 API, 2026-11-13)
