## CH-2: 안건 진행과 채팅방 종료 규칙

- 현재: 진행 중인 채팅방 하단에 `조율 확정 메뉴`가 있다(Figma `1715:38109`). 누르면 `다음안건 진행하기 | 매칭확정하기` 메뉴로 펼쳐진다(`1858:18417`). 메뉴는 입력창을 누르거나(디자이너 메모 `1858:18842`), Esc를 누르거나, 항목을 고르면 접힌다.
- 현재: `다음안건 진행하기`는 확인 창(`이대로 확정하시겠습니까?`) 뒤에 안건을 확정하고, 같은 자리가 `안건 확정 취소하기`로 바뀐다. 취소는 확인 없이 바로 된다.
- 현재: `매칭확정하기`는 확인 창(`매칭을 확정하시겠습니까?`, `1858:18674`) 뒤에 내 확정만 저장하고, 같은 자리가 `매칭확정 취소하기`로 바뀐다. 상대도 확정해야 최종 매칭이 되므로(확인 창 문구) 매칭 완료 처리는 서버 몫으로 남겼다. 시연 데이터는 내 선택만 메모리에 저장한다.
- 충돌: 확인 창은 `안건을 확정하면 다시 수정할 수 없어요`라고 안내하지만, Figma `988:16735`에는 확정 뒤 `안건 확정 취소하기` 상태가 있다. 지금은 취소 버튼을 유지했다.
- 문구: Figma의 `Ai가 다음 안건으로이동해요`를 `AI가 다음 안건으로 이동해요`로 띄어 썼다. 상대의 확정, AI 확정 카드, 다음 안건 표시는 서버 동작으로 보고 구현하지 않았다.
- 현재: `대화방에서 나가기`는 목록으로 이동만 한다. `채팅방 종료하기`는 채팅방을 종료 상태로 바꾼다. 종료 전 확인 창은 없다.
- 근거: 기획 메모 `897:12790`은 두 사용자 중 한 명만 눌러도 다음 주제로 넘어간다고 적었지만, Figma `988:16735`에는 누른 뒤 `안건 확정 취소하기` 상태가 있다.
- 질문: 한 명만 눌러도 넘어가는가, 둘 다 눌러야 하는가? 나가기와 종료는 어떻게 다른가? 종료 전에 확인 창이 필요한가? 매칭 확정은 언제 결정되는가? 매칭 확정 뒤에 상대에게 무엇을 보여주고, 내 확정을 취소할 수 있는가?
- 답변 전: 현재 임시 동작을 유지하고 서버 규칙으로 설명하지 않는다.

## 시연 데이터의 범위

모든 상대는 룸메이트 예시 데이터의 후보다. 이름과 매칭률이 같고, 상대 캐릭터를 누르면 그 후보의 매칭 분석이 열린다. Figma 목록의 한수희, 진서율은 룸메이트 데이터에 없어 이서윤, 박지민으로 바꿨다.

| 방     | 상태                       | 근거         |
| ------ | -------------------------- | ------------ |
| 민수정 | 매칭 확정                  | `940:19880`  |
| 이서윤 | 내가 다음 안건을 요청함    | `988:16735`  |
| 서유정 | 대화 중                    | `988:19036`  |
| 박지민 | 첫 안건 확정, 둘째 진행 중 | 예시로 작성  |
| 김혜나 | 대화 시작                  | 예시로 작성  |
| 남윤경 | 시작                       | `897:11605`  |
| 전혜윤 | 중간 종료                  | `1236:14142` |
| 최하은 | 시작                       | `897:11605`  |

시간은 `오늘`, `어제`, `2일전`, `3일전`으로 나눴다. 보낸 메시지, 투표, 종료는 메모리에만 반영되고 새로고침하면 처음 상태로 돌아간다.

## DE-C6: 채팅방 새 디자인의 빈 자리

- 현재: 채팅방을 Figma `1715:38109`로 바꿨다. 첫 메시지로 AI 소개 카드(`안건 조율을 시작할께요!`)와 조율 안건 목록을 보여준다.
- 챗봇 이름: Figma는 `챗봇이 이름`, `"00"`으로 비워 두었다. 지금은 `AI 챗봇`으로 표시한다.
- Figma에 없는 상태: 확정된 안건 카드는 `미정` 자리에 갈색 `확정` 배지를 붙였다. 확정한 뒤의 메뉴 문구(`안건 확정 취소하기`, `매칭확정 취소하기`), 보낼 내용이 없을 때 흐린 전송 버튼은 임시 디자인이다.
- 메뉴 버튼: Figma는 뒤로가기처럼 원 안에 그렸다. 뒤로가기와 같이 원은 hover와 키보드 포커스 때만 보인다.
- 질문: 챗봇 이름은 무엇인가? 확정 카드, 취소 버튼, 비활성 전송 버튼의 디자인은 무엇인가?
- 답변 전: 임시 표시를 유지하고 최종 디자인으로 간주하지 않는다.
