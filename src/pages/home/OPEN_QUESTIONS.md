## 매칭 전후 프레임의 차이

| 요소        | 매칭 전(`724:9392`)        | 매칭 후(`724:11202`)                                                   |
| ----------- | -------------------------- | ---------------------------------------------------------------------- |
| 로고        | 59×39                      | 45×29.75. 앱은 홈 두 상태와 룸메이트 리스트 모두 59×39(24, 9)로 맞췄다 |
| 종 아이콘   | 3px 오른쪽, 흰색 28px 배경 | 배경 없음                                                              |
| 종 색상     | `#6E5149`                  | `#614735`                                                              |
| 캐릭터 위치 | x 71                       | x 70                                                                   |
| 말풍선      | x 109, 오른쪽 아래 반경 6  | x 108, 반경 8                                                          |

매칭 전 프레임의 흰색 배경은 사용자 요청으로 구현에서 뺐다. 나머지는 각 프레임대로 구현했다.

## 확정된 흐름과 다른 Figma 문구

- 별도 `플로우 정리` 문구는 설문 결과 다음을 룸메이트 리스트로 적었다. 확정된 흐름에 따라 설문 결과에서 `홈화면으로 가기`로 홈에 들어온다.
- 같은 문구의 우선순위별 설문 구분은 별도 작업이다. 설문 순서와 로직은 바꾸지 않았다.

## 화면 크기

- 390×844 외 폭에서는 방 배경, 캐릭터, 말풍선이 폭에 비례해 커지거나 작아진다. 글자 크기는 인사말만 좁은 화면에서 줄어든다.
- 높이가 부족하면 하단 내비게이션 위의 내용만 스크롤된다.
