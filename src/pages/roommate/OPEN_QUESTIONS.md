## Figma 값이 카드마다 다른 부분

- 리스트 카드의 나이 칸 너비가 27~30px로 다르다. 글자 너비에 맞춰 표시한다.
- 상세 프로필 하단 버튼 프레임만 x 1에 놓여 버튼이 1px 오른쪽에 있다. 매칭 분석과 같은 x 24에 맞췄다.

## 시연 데이터의 범위

- Figma에 내용이 있는 후보는 `민수정`뿐이다. 여섯 번째 후보까지의 이름, 나이, 학과, 매칭률은 Figma 값이다.
- 일곱 번째부터의 후보 9명은 기능 확인을 위해 추가한 가상의 예시다. 이름, 나이, 학과, 매칭률 모두 Figma에 없다.
- 캐릭터 이미지는 Figma의 4종을 돌려 쓴다.
- 나머지 후보의 분석 문구는 화면 전환을 확인하려고 손으로 쓴 예시다. 계산 결과가 아니다.
- 나머지 후보의 상세 답변은 실제 설문 문항(`QUESTION_TOPICS`)의 보기에서 고른 예시다.
- 상세 프로필 카드는 마이페이지와 같은 묶음(잠버릇 1, 기상알람 2, 청소 청결 2, 개인 청결 2, 흡연유무 1)과 같은 카드를 쓴다. 표시하는 답변은 후보의 것이다.

## DE-R1: Figma 상세 프로필 예시와 실제 설문의 차이

`민수정`의 답변은 최신 Figma 설문요약카드 컴포넌트(`1377:37872`)를 그대로 옮겼다. 카드의 질문 문구는 실제 설문의 본인 문항을 쓴다.

| 주제      | Figma 질문 문구와의 차이              | Figma 답변과 실제 보기의 차이                                                |
| --------- | ------------------------------------- | ---------------------------------------------------------------------------- |
| 취침 시간 | `나는`이 없고 `몇시 쯤`으로 띄어 씀   | 원하는 성향 `조용하기만 하면 상관없다`가 실제 보기에 없음                    |
| 알람      | `나는`이 없음                         | 원하는 성향 `3~4번 까지는 괜찮다`는 실제 `3~4번까지는 괜찮다`                |
| 바닥 청소 | `나는`이 없고 `방바닥`으로 붙여 씀    | 나의 성향 `거의 매일 해야한다`는 룸메이트 문항의 보기(`거의 매일 해야 한다`) |
| 식기      | `나는`이 없고 `식가를`(식기를)로 표기 | 원하는 성향 `다음 날까지는 괜챃다`(괜찮다)                                   |
| 개인 물건 | `나는`이 없음                         | 실제 보기와 같음                                                             |
| 흡연      | `나는`이 없음                         | 실제 보기와 같음                                                             |
